# Тренажёр веб-разработки

Интерактивный образовательный веб-проект для детей и подростков, делающих первые шаги в веб-разработке. Тренажёр последовательно знакомит с основами HTML, CSS и JavaScript через практику, а не через сухую теорию: каждое задание показывает живой, визуальный результат действия ученика ещё до того, как он отправит ответ на проверку.

## Назначение проекта

Проект рассчитан на начинающих — прежде всего на детей школьного возраста, которые только знакомятся с устройством веб-страниц. Материал подаётся небольшими шагами, язык объяснений — простой и дружелюбный, а каждое задание сопровождается мгновенной обратной связью и пояснением, почему ответ верный или неверный.

## Как устроен тренажёр

Каждая тема curriculum построена по единой трёхчастной структуре.

1. **Теория.** Короткий интерактивный блок, в котором ученик сам управляет элементами интерфейса — переключает чекбоксы, двигает ползунки, кликает по фрагментам кода — и сразу видит, как меняется результат. Теоретические сведения подаются не текстом для заучивания, а через наблюдение за живым примером.
2. **Практика.** Серия как минимум из девяти заданий возрастающей сложности. Первые уровни предлагают выбрать правильный вариант или кликнуть по нужному элементу страницы, более поздние требуют самостоятельно написать HTML-разметку или CSS-правило. Ни одно задание не ограничивается текстовым вопросом без контекста — каждое показывает, как выбор ученика отражается на странице, прежде чем он нажмёт «Проверить».
3. **Проверь себя.** Колода из десяти карточек «Верно или неверно», которые можно листать вперёд и назад. Каждая карточка — короткое утверждение по теме; после ответа ученик сразу видит, верно оно или нет, и короткое объяснение.

Прогресс по каждой теме сохраняется в локальном хранилище браузера, поэтому ученик может вернуться к занятиям позже и продолжить с того места, на котором остановился.

## Структура курса

Веб-темы разложены по 13 урокам курса, по 3–5 тем в каждом. Тема стоит в уроке, проект которого её использует, и не повторяется в других уроках; если приём нужен во многих проектах, тема отдана менее загруженному уроку. На главной странице уроки сворачиваются и разворачиваются, у каждой темы есть метка файла: HTML (index.html) или CSS (style.css).

1. **Сайт про себя** — структура HTML-документа (lang, viewport), теги и атрибуты, заголовки h1–h6, абзац p.
2. **Меню кафе «Тыковка»** — подключение стилей, цвет фона, списки ul и ol.
3. **Музеи мира** — ссылки, изображения, пути к файлам, цвет текста.
4. **Список рецептов** — блочная модель, выравнивание текста, ширина и высота в px и % (новая тема).
5. **Урон оружия CS:GO** — таблицы (border-collapse, border-spacing), рамки, закреплённый блок position: fixed (новая тема).
6. **Форма регистрации** — форма, поля и label, типы полей (maxlength), grid, плавные переходы.
7. **Лучший дизайн** — палитра и шрифты (новая тема), шрифты и оформление текста, селекторы.
8. **Баннер** — фоновое изображение, кнопки (cursor: pointer), курсив font-style (новая тема).
9. **Личная визитка** — max-width и max-height (новая тема), тени и скругления, насыщенность шрифта.
10. **Интерактивные картины** — прозрачность opacity, псевдоклассы :hover и :active, блоки div и классы.
11. **Подвал страницы** — атрибут id, сброс отступов и box-sizing, макет с подвалом внизу, семантические теги.
12. **Стоимость услуг** — маркеры списка list-style (новая тема), flexbox, размер текста.
13. **Сайт обо мне 2.0** — сайт из нескольких страниц (новая тема), подчёркивание text-decoration (новая тема), единицы em, rem и vh (новая тема).

**Дополнительно** — градиент linear-gradient и доступ к элементам из JavaScript: эти темы не встречаются в проектах уроков.

Новые CSS-темы собраны на общем шаблоне: теория с живыми примерами, затем задания «выбери вариант» и «напиши CSS». Написанный код проверяется по готовым стилям элемента в окне предпросмотра, поэтому засчитывается любая верная запись.

### Python — первые программы (main.py)

Отдельный раздел со своей главной страницей. Код выполняется прямо в браузере встроенным интерпретатором подмножества Python (переменные, условия, циклы for и while, отступы блоков), который выдаёт настоящие сообщения об ошибках Python и пояснения к ним на русском языке. Каждая тема начинается с игровых миссий: ученик учит робота Пикселя говорить и слушать, получает опыт и звания.

- Вывод на экран: print — текст и числа, вычисления, несколько значений, параметр sep, перенос строки.
- Ввод данных: input — вопросы пользователю, переменные, преобразование ответа в число через int; в терминале можно отвечать программе, а проверка запускает решение с разными ответами.
- Переменные — создание, изменение и имена переменных, +=, -=, *=, целочисленное деление // и остаток %.
- Условия: if — сравнения, else, elif, and, or, not и типичные ошибки (двоеточие, отступ, = вместо ==).
- Цикл for — range с началом, концом и шагом, переменная цикла, перебор букв строки, накопление суммы.
- Цикл while — счётчик, бесконечный цикл и как его избежать, повтор до нужного ответа, break и continue.

## Возможности

- Исключительно практико-ориентированные задания: каждое упражнение демонстрирует результат вживую, без абстрактных вопросов без контекста.
- Постепенное усложнение внутри каждой темы — от распознавания правильного варианта к самостоятельному написанию кода.
- Проверочные карточки «Верно или неверно» для закрепления материала в конце каждой темы.
- Переключение светлой и тёмной темы оформления с сохранением выбора пользователя.
- Сохранение прогресса в браузере только с согласия пользователя: вопрос задаётся один раз, на первом экране страницы курсов; вход ученика или педагога тоже считается согласием.
- Тренажёры открываются только после входа в аккаунт; без входа показывается экран со ссылкой на вход.
- Счётчик очков и личная страница «Мой прогресс» со статусом каждого уровня, датами прохождения, временем занятий и последними заданиями.
- Учёт времени: засчитывается только активная работа — вкладка открыта и ученик что-то делает; время на уровне идёт, пока практика видна на экране.
- Вход и аккаунты на странице курсов (https://tashako12.github.io/my-projects/): вход по коду участника или создание аккаунта (имя и первые три буквы фамилии, код выдаётся сразу), там же рейтинг учеников; тренажёры используют то же хранилище браузера. Выход стирает прогресс с компьютера, сохранив его на сервере, что удобно для общих компьютеров в классе.
- Кабинет педагога (кнопка «Вход педагога» на странице курсов): по постоянному коду единственного админа; сводка по темам и подробный прогресс каждого участника — уровни, даты и время.
- Код участника: с согласия ученика прогресс хранится на сервере (Supabase) под постоянным уникальным кодом вида K7QM-2XWD, который выдаёт сама база, и автоматически обновляется после каждого задания; на другом компьютере достаточно ввести код. Для идентификации сохраняются только имя и первые три буквы фамилии.
- Запасной код восстановления: весь прогресс упаковывается в код, который переносит его на другой компьютер без сервера.
- Игровой слой: восемь званий по опыту (от «Новичка» до «Легенды кода», шкала рассчитана на все очки курса плюс 1000 в запас), 12 достижений, серии верных ответов подряд, звёзды за каждую тему и уведомления о новых наградах.
- Миссии в каждой HTML-теме: Пиксель собирает свой сайт, ученик пишет разметку или перетаскивает нужные теги из набора (в нём есть и пара лишних) и сразу видит результат; проверка разбирает страницу, а не сравнивает текст.
- Кабинет педагога: сводка «Где чаще ошибаются» с переходом прямо к нужному уровню; педагог может засчитать ученику уровень, миссии или всю тему — отметки хранятся отдельно и подтягиваются на устройство ученика.
- Робот Пиксель на каждой странице заданий: бежит вслед за прокруткой, радуется верным ответам, подбадривает после ошибок и иногда дурачится.
- Рейтинг учеников по сезонам с тематическим оформлением (на странице курсов).
- Материал и формулировки адаптированы для восприятия детской аудиторией.

## Технологический стек

Vite, React, TypeScript, Tailwind CSS. Сайт статический; для кодов участника используется база Supabase: таблица закрыта, доступ только через функции из `supabase/schema.sql`.

## Локальная разработка

```bash
npm install
npm run dev
```

## Сборка проекта

```bash
npm run build
npm run preview
```

## Публикация

При пуше в ветку `main` сборка и публикация на GitHub Pages выполняются автоматически через GitHub Actions (`.github/workflows/deploy.yml`). Для первого запуска публикации необходимо один раз включить её в настройках репозитория: **Settings → Pages → Source → GitHub Actions**.
