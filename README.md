# 🧩 Тренажёр веб-разработки

Интерактивный тренажёр для первых шагов в вёрстке и JavaScript. Каждая тема
устроена одинаково: сначала короткая **интерактивная теория** с живыми,
подвижными элементами, потом **практика из нескольких уровней** — слева
список уровней, сначала выбираешь ответ из списка или кликаешь по
странице, дальше уровни усложняются и просят написать ответ самому.
Никаких абстрактных тестовых вопросов — каждое задание показывает
результат вживую.

Темы идут по возрастанию сложности и разбиты на три раздела — **сначала всё
HTML** (разметка, index.html), **потом всё CSS** (оформление, отдельный файл
style.css — это специально подчёркнуто на каждой CSS-странице), и в конце
немного **JavaScript**.

## Темы

### 📄 HTML — разметка (index.html)

- 🧩 **Что такое теги и атрибуты** — разбери HTML-тег на части и собери свой.
- 🏗️ **HTML-теги и структура страницы** — скелет страницы: doctype, head, body.
- 🔠 **Заголовки `h1–h6`** — один главный заголовок и заголовки разделов поменьше.
- 📄 **Абзац `p`** — отступы абзаца и склеивание лишних пробелов.
- 📑 **Списки `ul`, `ol` и вложенные** — маркированные, нумерованные и списки внутри пункта.
- 🗂️ **Блоки `div` и классы** — div как контейнер, `class`/`id` как зацепка для CSS.
- 🔘 **Кнопка `button`** — для действий на странице, `disabled`.
- 🖼️ **Изображения `img`** — `src`, `alt`, `width`, `height`.
- 🧭 **Пути к картинкам** — собери `src` сам и увидь вживую, когда фото появляется, а когда нет (относительные пути, `../`, регистр букв).
- 🔗 **Тег `a` и атрибут `href`** — собери ссылку сам: на страницу сайта, во внешний сайт, к разделу страницы, в почту.
- 🏛️ **Семантические теги** — `header`, `nav`, `main`, `aside`, `footer`, `article` — смысл, а не просто div.
- 📊 **HTML-таблицы** — `table`, `tr`, `td`, `th`, `rowspan`, `colspan`.
- 📋 **Форма `form`** — объединяет поля в одну отправку.
- 🏷️ **Поля формы: `label` и `placeholder`** — подпись, которая не исчезает, и подсказка, которая исчезает.
- ⌨️ **Типы полей ввода** — `type`, `placeholder`, `required` на примере формы регистрации.

### 🎨 CSS — оформление (style.css, отдельный файл!)

- 🔌 **Как подключить стили** — `<link rel="stylesheet" href="style.css">`, синтаксис `селектор { свойство: значение; }`.
- 🎯 **CSS-селекторы** — пиши селекторы и смотри, какие элементы страницы они выбирают (по-настоящему, через `querySelectorAll`).
- 🎨 **Цвет текста `color`** — подбери и впиши значение цвета, смотри вживую.
- 🪣 **Цвет фона `background-color`** — не перепутай с `color`.
- 📐 **Выравнивание текста `text-align`** — `left`, `center`, `right`, `justify`.
- 🔡 **Размер текста `font-size`** — обычно в пикселях.
- 🅱️ **Насыщенность шрифта `font-weight`** — от 300 до 900, bold = 700.
- 🔤 **Шрифты и оформление текста** — `font-family`, `letter-spacing`, `line-height`, `@font-face` vs `@import`.
- 📦 **CSS Box Model** — подвигай слои `margin`, `border`, `padding` и посмотри, как считается итоговый размер блока.
- 🔲 **Рамка: `border` и `border-bottom`** — толщина, стиль линии и цвет.
- 🪪 **Тени и скругления** — `border-radius` и `box-shadow`: скругли уголки и подвинь тень карточки.
- 🏞️ **Фон блока: background-image** — `background-size`, `background-position`, `background-repeat` вживую.
- 🌈 **Градиент `linear-gradient`** — плавный переход цветов вместо обычной картинки.
- 🧹 **Сброс отступов: `*` и `box-sizing`** — убираем умолчания браузера и чиним формулу ширины блока.
- 🧲 **Flexbox** — живые свойства `flex-direction`, `justify-content`, `align-items`, `flex-wrap`.
- ▦ **CSS Grid** — `grid-template-columns` и `gap` расставляют карточки ровной сеткой.
- 🧱 **Макет страницы: header, main, footer** — прижимаем footer к низу экрана через flexbox.
- 🖱️ **Псевдоклассы `:hover` и `:active`** — живая карточка, реагирующая на курсор и клик.
- 🫥 **Прозрачность `opacity`** — от 0 до 1, место под элементом остаётся занятым.
- 🌀 **Плавные переходы `transition`** — сглаживает смену состояний, например при `:hover`.

### ⚙️ JavaScript (script.js)

- 🧰 **Доступ к элементам HTML в JS** — `getElementById`, `querySelector(All)`, `children`, `closest`, `parentElement`, `nextElementSibling`...

Прогресс по каждой теме сохраняется в `localStorage` браузера.

## Стек

Vite + React + TypeScript + Tailwind CSS, без бэкенда — чистый статический
сайт.

## Разработка

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

## Деплой

При пуше в `main` GitHub Actions (`.github/workflows/deploy.yml`) собирает
проект и публикует его на GitHub Pages. Один раз нужно включить Pages в
настройках репозитория: **Settings → Pages → Source → GitHub Actions**.
